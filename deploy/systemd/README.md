# systemd units

User units, so LifeOps runs without root.

```bash
mkdir -p ~/.config/systemd/user
cp deploy/systemd/*.service ~/.config/systemd/user/
# Adjust WorkingDirectory in lifeops-core.service if the repo is elsewhere.
systemctl --user daemon-reload
systemctl --user enable --now lifeops-nornicdb lifeops-core
```

Keep them running after logout:

```bash
loginctl enable-linger "$USER"
```

Status and logs:

```bash
systemctl --user status lifeops-core
journalctl --user -u lifeops-core -f
```

Both units read the NornicDB credential from
`~/.local/share/lifeops/nornicdb.env`, generated by `scripts/nornicdb.sh` on
first start. It is never committed.

The Console is not a unit. In development it runs under Vite; in production,
build it (`make console-build`) and serve `console/dist` from any static web
server.
